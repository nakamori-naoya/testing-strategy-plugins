# X のクローンのフォローからホームタイムラインまでの経路に固有の条件

この経路は、フォローの成功がデータベースへの確定で決まり、ホームタイムラインへの反映は非同期に行われる。ログインは外部の認証サービスが担う。この条件は、その題材で E2E シナリオが外しやすい判断を型にしたものである。

### xe-async-to-timeline

重み: 3

PASS：フォローの成功から、非同期の反映を経て、フォローした相手のポストをホームタイムラインで読めるまでを一つの経路として確かめ、反映の完了を、ホームタイムラインの読み取りか反映の完了の記録のような外から観測できる条件を期限付きで待って判断している。

FAIL：フォローの応答だけで完了とみなしている、または反映を固定の時間で待っている。

### xe-idp-official-path

重み: 2

PASS：外部の認証サービス（ログイン）は制御できない境界として扱い、その公式のテスト用経路を使う実物の接続を既定にするか、使えない理由と代替、実物との差、差を確かめる場所を書いている。認証サービスの向こう側の画面操作のように自動化できないものだけを代替している。

FAIL：外部の認証サービスを理由なく自作の偽物に置き換えている、または認証の扱いが書かれていない。

### xe-stores-real

重み: 2

PASS：データベース、キャッシュ、メッセージングは、実構成（ローカルのエミュレーターを含む）の実物を通している。

FAIL：経路の途中のデータベース、キャッシュ、メッセージングのどれかを差し替えている。
